## About JILLU Games

JILLU Games is an open-source initiative dedicated to building reusable game interfaces, frontend engines, animation systems, and interactive technologies for developers worldwide.

Our projects are made for developers, designers, educators, and curious builders who want to learn, experiment, and ship engaging experiences on the modern web and mobile platforms.

## What We Build

| Area | What you can expect |
|---|---|
| 🎮 **Game Frontend Engines** | Reusable foundations for responsive, interactive game experiences |
| 🧩 **Reusable UI Components** | Modular interfaces that make game interactions clearer and more expressive |
| ⚡ **Interactive Web Experiences** | Browser-first experiments and polished frontend patterns |
| 🎨 **Animation Systems** | Motion, feedback, and transitions that bring interfaces to life |
| 🛠 **Developer Tools** | Utilities and workflows that support faster game development |
| 📚 **Learning Resources** | Practical examples and documentation for building with confidence |

## Open Source Philosophy

JILLU Games believes in:

- **Sharing knowledge** so more developers can build and learn in public
- **Developer collaboration** through welcoming discussions and thoughtful reviews
- **Clean code** that is readable, maintainable, and useful as a reference
- **Accessible technology** that lowers the barrier to experimentation
- **Community contribution** that gives every improvement a place to start

## Contributing

There are many ways to contribute:

- Report a reproducible bug
- Suggest a focused feature or improvement
- Submit a code change
- Improve documentation or examples
- Refine an interaction or UI detail
- Share feedback from your own experiments

Before opening a contribution, please check the relevant repository guidance and keep changes focused. Clear context, small pull requests, and useful examples make collaboration easier for everyone.

## Community Guidelines

We ask everyone participating in JILLU Games to:

- Treat contributors and maintainers with respect
- Follow the conventions documented by each project
- Give constructive, specific feedback
- Keep discussions focused on the work and the learning
- Maintain clean, ethical, and accessible development practices

## License & Usage

Each JILLU Games project includes its own license and usage terms. Before using or redistributing a project, please review:

- The repository's license requirements
- Attribution and notice obligations
- Permissions for third-party code, fonts, sounds, and visual assets

If a repository does not yet state its license clearly, please open an issue before relying on it in a larger project.
